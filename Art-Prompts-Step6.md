## run

Use case: stylized-concept. Asset type: production SPRITE SHEET for an actual Unity game. Input image 1 is a CHARACTER DESIGN REFERENCE ONLY, not an edit target. Recreate same brown-haired olive-jacket survivor, backpack, dark pants, boots, in sharp pixel art, smaller practical 48x64 logical pixels per frame. Generate exactly FOUR running animation frames arranged in a precise 2 columns x 2 rows grid, with four equal SQUARE cells, on a square transparent canvas. Each character entirely inside its own cell with equal transparent margins; no overlap and nothing crossing cell boundaries. Reading order top-left, top-right, bottom-left, bottom-right. All frames face RIGHT. Upper torso, head, arms and hand grip stay at EXACTLY the same position and scale in every cell, hands held at stomach/chest height extended toward the right, empty hands ready to grip a separately rendered pistol. Leg cycle MUST visibly change: frame 1 left leg far forward right leg back; frame 2 legs passing under hips with back knee bent; frame 3 right leg far forward left leg back; frame 4 opposite passing position. Keep identical top of head and foot baseline, identical face/hair/clothes/backpack and identical body proportions. Slight top-down three-quarter classic 2D RPG character view matching reference. Pixel art with clear chunky pixels. Actual transparent alpha around ALL FOUR figures. No gun drawn, no ground, no shadows, no borders, no grid lines, no numbering, no text, no labels, no checkerboard background. Deliver a square perfectly regular 2x2 sprite atlas, not four unrelated illustrations.

## pistol

One single compact semiautomatic handgun viewed from SIDE, muzzle points exactly RIGHT horizontally, grip points down-left, worn charcoal metal slide with readable lighter gray top edge, small dark brown grip. Clean sharp chunky pixel art, approximately 32x20 logical pixels enlarged with crisp square pixels. Full gun visible, fills most canvas with small transparent margin. This will be held by an olive-jacket survivor sprite in a top-down 2D survival game. Gun ONLY, no hands, no person, no bullets, no muzzle flash, no ground or background, no text, no labels. Genuine transparent alpha. Strong readable silhouette on gray asphalt, subtle pale edge highlights. Not a photoreal render, not perspective, not isometric.
